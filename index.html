SVG → Complex Fourier Equations

Upload a vector logo. This tool samples its SVG paths, calculates Fourier coefficients, animates the reconstruction, and exports the equations.

How to use: download an emblem as an .svg file, choose it below, then press Calculate Fourier equations. This runs locally in your browser.
Choose an SVG file to begin.
After calculation, each path's complex Fourier series will appear here.

Each contour gets its own Fourier series. Fourier series are periodic, so open strokes can gain a joining segment. Basic SVG shapes are supported; complex SVG features such as clipping, masks, filters, and external CSS may not reproduce exactly. More harmonics preserve finer detail but cannot fix missing or unsuitable source geometry.

Gold lines are the reconstructed curves. The bright point follows the path being drawn. If the SVG contains many paths, they are traced in order of path length.
